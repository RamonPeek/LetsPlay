# Let’s Play Guitar Center

A responsive Dutch Astro website for Let’s Play Guitar Center in Eindhoven. The design uses the original logo, black/yellow/red palette, shop photography, and Montserrat, paired with Barlow Condensed for the poster-style headings.

## Development

Requires Node.js 22.12 or newer.

```sh
npm install
npm run dev
```

Open http://localhost:4321. To validate and build:

```sh
npm run check
npm run build
npm run check:seo
npm run preview
```

The production website is generated in `dist/`. The build writes `dist/_redirects` for Netlify or Cloudflare Pages from `redirects.mjs`. Other hosts need equivalent HTTP 301 rules; Astro’s generated HTML redirect pages provide a browser fallback. Configure the host to serve `404.html` with HTTP status 404 for missing URLs.

Run `npm run format` to format the source with Prettier and its Astro plugin.

## Content and pages

- 29 content pages: eight main pages, a teacher directory, 17 original teacher profiles, lesson rates, repair prices, and lesson terms. A custom 404 page is also included.
- Edit business details, navigation, hours, and service copy in `src/data/site.ts`.
- Shared layout and navigation live in `src/layouts/` and `src/components/`.
- Styling and responsive layouts live in `src/styles/global.css`.
- Teacher biographies and external portrait URLs live in `src/data/teachers.ts`; the published lesson terms are preserved in `src/data/lesson-terms.json`.
- Fonts and the existing main photography are local. New teacher portraits use external URLs from the original site, as requested; no portraits were downloaded. Keep those WordPress upload URLs accessible when replacing the old site.
- Unique SEO titles/descriptions and social images live in `src/data/seo.ts`. Canonical URLs, social metadata, MusicStore/WebSite/WebPage structured data, and breadcrumbs are generated by the shared layout. The sitemap and robots file derive their production domain from `site` in `astro.config.mjs`.

Development pages use `noindex`. For a staging build, set `SITE_INDEXABLE=false`; production defaults to indexable. `.env.example` documents this setting. To check a separate staging output on the same filesystem:

```sh
SITE_INDEXABLE=false npm run build -- --outDir .astro/seo-staging
node scripts/check-seo.mjs .astro/seo-staging --staging
```

`npm run check:seo` audits the built production HTML, sitemap, redirects, original URL coverage, and internal discoverability. See [the live-site SEO comparison](docs/seo-audit.md) for findings and deployment checks.

The webshop remains at https://webshop.letsplayguitarcenter.nl/ and opens in a new tab. There is no local shopping cart or checkout.

The trial-lesson enquiry form validates the fields and opens the visitor’s email program with a prefilled request. The visitor must send that email to complete the enquiry. A phone link and a clear message provide an alternative. Automatic form delivery would require a mail service or backend integration.
